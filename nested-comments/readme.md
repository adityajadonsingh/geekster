# Nested Comment Section

A simple web application that implements a nested comment section using HTML, CSS (Tailwind CSS), and JavaScript. The application allows users to add comments, replies, edit, and delete comments and replies, making it a fully interactive comment system similar to many social media platforms.

## Features
- **Add Comments**: Users can add a comment at the top level.
- **Add Replies**: Users can reply to any comment, creating a nested structure.
- **Edit Option**: Each comment and reply has an edit option to modify its content.

## Technologies Used
- **HTML**: The structure of the comment section.
- **CSS**: Styling the UI, providing a modern and responsive design.
- **JavaScript**: Adding interactivity like adding, editing, and deleting comments and replies.

## Project Setup

### Prerequisites
Ensure you have the following installed:
- A modern web browser (Chrome, Firefox, etc.)
- An editor to modify the code (VS Code or similar)
- Basic understanding of HTML, CSS, and JavaScript

### Installation
1. Repository:
    https://github.com/adityajadonsingh/geekster/tree/JavaScript-Practice/nested-comments

2. Open the project folder:
    ```bash
    cd nested-comment-section
    ```

3. Open the `index.html` file in your web browser to view the project.

## How to Use
1. Open the app in your browser.
2. To add a comment, type in the input box at the top and click **Add Comment**.
3. To reply to a comment, click the **Reply** button below the respective comment.
4. To edit a comment or reply, click the **Edit** button beside the comment.
5. To delete a comment or reply, click the **Delete** button.
